# Endless Drawing

**[endlessdrawing.com](https://endlessdrawing.com)**

**One drawing. Everyone. Forever.**

Один общий бесконечный холст. Никакого приветственного экрана, никаких баннеров — только общий холст. Инструменты появляются по правому клику или долгому нажатию.

## Статус

Публичный `/` — **общий мир через backend** (`/ws`, протокол v1): штрихи сохраняются сервером, видны всем посетителям в реальном времени и возвращаются после reload. Удалять (ластиком или undo) можно только свои штрихи текущей сессии вкладки; право проверяет сервер. Разрыв соединения не теряет нарисованное: неподтверждённые штрихи остаются на экране и повторно отправляются с тем же UUID после переподключения.

Реализованы Canvas 2D, DPR/resize, камера с **ограниченным зумом 16–400%**, кисти round/square/`chisel`/`spray`, цвет/толщина/opacity, палитра с Undo и масштабом, рука, wheel, Space/средняя кнопка, ластик, undo, **touch и Apple Pencil (iPhone/iPad)**: рисование пальцем/пером, два пальца — перемещение и pinch-зум, долгое нажатие — палитра, bottom sheet на телефоне. Favicon — `public/favicon.png` (исходник `docs/design/favicon-source.png`), логотип поверх холста не добавляется.

**Проверено:** локальная связка этот frontend ↔ backend ↔ PostgreSQL в Chromium/Firefox/WebKit (`npm run test:integration`). **Не проверено:** реальные iPhone/iPad (palm rejection, жесты ОС, Safari iOS), HTTPS-стенд/VPS, нагрузка. Admin `/admin/` — отдельно, см. ниже.

## Запуск

Node >=22.12, npm:

```sh
npm ci
npm run dev           # http://127.0.0.1:5173
npm run check
npm test
npm run build         # dist/
npm run preview       # локальная проверка production-сборки
npx playwright install chromium
npm run test:e2e       # Chromium
npx playwright install firefox webkit
npm run test:e2e:all   # Chromium + Firefox + WebKit
```

### Совместная проверка с backend

```sh
npm run build
# в ../endless-drawing-backend (PostgreSQL из его docker compose):
STATIC_DIR=../endless-drawing-frontend/dist cargo run
# здесь:
npm run test:integration   # два/три реальных браузерных контекста против :3000
```

Тест рисует в случайной области мира, поэтому совместим с непустой dev-БД, но оставляет в ней удалённые (soft delete) тестовые штрихи — лучше использовать отдельную БД.

### iPhone / iPad в локальной сети

```sh
npm run dev:lan                     # Vite на 0.0.0.0:5173
# backend: разрешить Origin телефона (IP вашего Mac)
ALLOWED_ORIGINS=http://192.168.1.10:5173 cargo run
```

Открыть `http://192.168.1.10:5173` на устройстве. По HTTP страница не является secure context: UUID генерируются fallback-функцией через `crypto.getRandomValues`, остальное работает. Admin по HTTP не работает (нужны Secure cookies/WebAuthn).

Vite proxy `/ws`, `/api/admin/*`, `/healthz`, `/readyz` → `http://127.0.0.1:3000`. Для другого backend: `BACKEND_DEV_URL=http://127.0.0.1:8080 npm run dev`. Без запущенного backend холст открывается, но штрихи остаются неподтверждёнными (кратко сообщается об отсутствии соединения). В production-коде mock нет; E2E используют WS-двойник `tests/e2e/support/world.ts`. Сборка включает `dist/index.html`, `dist/admin/index.html` и общие assets: передавать backend целый `dist/`.

## Администратор и модерация

Предусмотрен отдельный служебный вход `/admin/`, без кнопок и ссылок на публичном холсте: логин + сложный пароль + обязательный WebAuthn passkey с user verification, включая Touch ID. Platform/synced passkeys разрешены; требуются основной и отдельный резервный credential, а не один синхронизированный ключ на двух устройствах. Нужны серверная сессия, CSRF-защита, выбор/подтверждение скрытия чужих штрихов с причиной, live-уведомление всех посетителей и закрытый аудит.

**Реализовано во фронтенде:** отдельный `/admin/` entry, EN/RU, server-session check, пароль → WebAuthn → verify, регистрация двух passkeys, read-only WS snapshot/live, панорамирование, выбор до 100 чужих штрихов, список UUID/причина/подтверждение, HTTP hide, проверка неопределённой операции/явный идентичный retry, 401/expiry/logout. Секреты/CSRF не сохраняются в Storage; публичный entry не загружает admin UI. Прямоугольное выделение пока не добавлено — множественный выбор кликами.

**Не считать production-интеграцию готовой:** API-контракт — `../endless-drawing-backend/docs/admin-api.md`, backend проверен локально; frontend HTTP/WS E2E использует mocks. Настоящие Touch ID, независимый резервный провайдер, cookie/CSRF/Origin на доверенном HTTPS, CLI provisioning и удаление в двух публичных контекстах нужно проверить совместно. HTTP Vite preview не обходит Secure cookies/серверную политику. Скрытый URL/Storage-флаг не авторизация. Инструкция и границы: [docs/admin-frontend.md](docs/admin-frontend.md).

## Управление

| Ввод | Действие |
| --- | --- |
| ЛКМ / перо / один палец | Активный инструмент: кисть / рука / ластик |
| Правый клик, Shift+F10, ContextMenu, долгое нажатие (500 мс) | Палитра |
| Зажатый Space (просто вести мышью или перетаскивать) / средняя кнопка | Временная рука: холст едет за курсором, при отпускании Space — прежний инструмент |
| Wheel / trackpad | Двухосевое панорамирование |
| Ctrl/⌘ + wheel, pinch трекпада | Зум вокруг курсора, 16–400% |
| Два пальца | Перемещение + pinch-зум; отменяет незавершённый штрих |
| Ctrl/⌘ + `=` / `-` / `0` (фокус на холсте) | Зум ×1.25 / ÷1.25 / 100% |
| Ctrl/⌘+Z, кнопка «Отменить» в палитре | Удалить последний свой штрих сессии |
| Escape | Закрыть палитру / отменить жест |

После первого касания пером (Apple Pencil) пальцы на этой странице только перемещают/масштабируют холст и не рисуют — ладонь не оставляет следов; касание пальцем во время штриха пером игнорируется. Оставшийся после pinch палец не начинает рисовать, нужен новый жест. На touch-ластик срабатывает по тапу/движению, а не при удержании.

Палитра доступна с клавиатуры; ввод в её полях не перехватывается горячими клавишами холста. Ширина 1–64 (world units, на экране масштабируется зумом), opacity 0.01–1, произвольный `#RRGGBB`, 6 быстрых цветов. По умолчанию round, #202020, 6, opacity 1. Допуск ластика — 4 CSS px на экране. На touch-устройствах цели ≥44 px, поле HEX 16 px (без автозума iOS); на телефонах палитра — нижний лист с учётом safe area.

## Языки

Английский — по умолчанию, русский — для `ru` и региональных вариантов (`ru-RU`, `ru-KZ` и т. п.). При загрузке выбирается первый поддерживаемый язык из `navigator.languages` в порядке предпочтений браузера. При пустом списке используется `navigator.language`, без совпадений — английский. Например, `de-DE, ru-RU, en-US` → русский, `en-US, ru-RU` → английский.

Переведены палитра, подсказки, сообщения ошибок и accessibility-подписи; `html.lang` и формат процентов соответствуют языку. Название Endless Drawing и фраза проекта не переводятся. Язык не сохраняется в Storage, настройки кисти от него не зависят. После изменения языка браузера достаточно перезагрузить страницу. Никаких экранов выбора или постоянных переключателей.

Публичный словарь и чистая функция определения языка — `src/i18n.ts`, отдельный admin-каталог — `src/admin/i18n.ts`; новые ключи проверяются TypeScript для обоих переводов. Дополнительные библиотеки и сетевые запросы переводов не нужны.

## Хранение и ограничения

- `localStorage`: `endless-drawing.preferences.v1` — инструмент и кисть.
- `sessionStorage`: `endless-drawing.camera.v1` — центр и zoom; `endless-drawing.session.v1` — 32-байтный base64url секрет сессии (отправляется только в WS `hello`); `endless-drawing.undo.v1` — UUID своих подтверждённых штрихов (до 500). Новая вкладка — новый секрет и стартовая точка из `hello.ack.spawn` (рядом со случайным живым штрихом, так посетители расходятся вслед за рисунком); в пустом мире — случайный центр в [-250, 250]. Закрытие вкладки завершает право удалять её штрихи.
- Геометрия хранится сервером; клиент держит кеш текущей подписки (до 20 000 штрихов / 1 000 000 точек, при переполнении — краткое сообщение) и до 64 неподтверждённых штрихов. Подписка — 3× видимая область, не шире 30 000 world units по оси, со сдвигом вперёд по направлению движения; переподписка, когда впереди остаётся меньше половины запаса, или при сильном увеличении. Штрихи нового snapshot появляются по мере прихода chunks.
- Повреждённые/недоступные Storage не ломают приложение (секрет тогда живёт до перезагрузки).
- Клиентские лимиты ниже серверных: create 5/1.1 с, delete 20/1.1 с, subscribe ≤4/с; ack timeout 12 с → переподключение и повтор того же UUID.
- Единый Canvas renderer, opacity за один draw call на штрих, Path2D кешируются. Публичный холст рисует confirmed-штрихи через кеш тайлов (`src/tiles.ts`): pan и рисование поверх плотной сцены копируют готовые тайлы вместо перерисовки всех путей; перерисовка только dirty RAF.
