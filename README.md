# Endless Drawing

**[endlessdrawing.com](https://endlessdrawing.com)**

**One drawing. Everyone. Forever.**

Один общий бесконечный холст. Никакого приветственного экрана, никаких баннеров — только общий холст. Инструменты появляются по правому клику или долгому нажатию.

## Статус

Публичный `/` — **общий мир через backend** (`/ws`, MessagePack v6/v5/v4/v3/v2 либо JSON v1): штрихи сохраняются сервером, видны всем посетителям в реальном времени и возвращаются после reload. Удалять (ластиком или undo) можно только свои штрихи текущей сессии вкладки; право проверяет сервер. Разрыв соединения не теряет нарисованное: неподтверждённые штрихи остаются на экране и повторно отправляются с тем же UUID после переподключения.

Реализованы холст (WebGL2 с кешем тайлов в текстурах, а без него Canvas 2D с тайлами), DPR/resize, камера с **ограниченным зумом 16–400%**, кисти round/square/`chisel`/`spray`, цвет/толщина/opacity, палитра с Undo и масштабом, рука, wheel, Space/средняя кнопка, ластик, undo, **touch и Apple Pencil (iPhone/iPad)**: рисование пальцем/пером, два пальца — перемещение и pinch-зум, долгое нажатие — палитра, bottom sheet на телефоне. `?renderer=canvas2d` оставляет прежний растровый кеш. Favicon — `public/favicon.png` (исходник `docs/design/favicon-source.png`), логотип поверх холста не добавляется. Полное приложение для iPad (Metal, жесты Apple Pencil) — отдельный будущий клиент того же протокола; этот репозиторий его не содержит.

**Проверено:** локальная связка этот frontend ↔ backend ↔ PostgreSQL в Chromium/Firefox/WebKit (`npm run test:integration`). Владелец 18.11.2026 на iPad Pro M4: прокрутка и рисование плавные, ладонь не рисует и не двигает холст, палец навигирует, поворот и уход в фон проходят. Публичный сайт отдаёт WebGL-сборку с тайлами. **Не проверено:** жесты от краёв экрана, iPhone, плотный spray при 16% и память тайлов. Admin `/admin/` — отдельно, см. ниже, и рисует Canvas 2D.

## Аналитика посещений

Cloudflare Web Analytics подключается через `src/analytics.ts` только в production-сборке на `https://endlessdrawing.com`: холст `/` и информационные `/about`, `/privacy`, `/terms`. Публичный токен счётчика — не API-ключ. Dev, localhost/preview, другие домены и `/admin/` не загружают beacon; автоматическую вставку Cloudflare держать выключенной, чтобы не дублировать ручную установку. Скрипт грузится асинхронно, блокировщик не препятствует рисованию. SPA tracking выключен: pan/zoom/рисование не создают отдельных просмотров.

Статистика после публикации — **Cloudflare → Web Analytics → endlessdrawing.com**: Visits/Page views за выбранный период, страны и источники переходов. Это приблизительные посещения, не точное число уникальных людей. Из приложения не отправляются custom events, рисунки, координаты или ключи владельца; обычный beacon получает сведения о странице/браузере, как описано на `/privacy` (EN/RU, включая статический текст без JS). Нативный iPad-клиент не меняется.

Перед browser tests выполнить `npm run build`: тест аналитики открывает production `dist` на перехваченном production origin, подменяет beacon и весь HTTP/WS, не обращаясь к живому сайту или счётчику. Наличие кода не подтверждает поступление статистики в Cloudflare: это проверяется после deploy в панели.

## Запуск

Node >=22.12, npm:

```sh
npm ci
npm run dev           # http://127.0.0.1:5173
npm run check
npm test
npm run build         # dist/
npm run preview       # локальная проверка production-сборки
npx playwright install chromium
npm run test:e2e       # Chromium
npx playwright install firefox webkit
npm run test:e2e:all   # Chromium + Firefox + WebKit
```

### Совместная проверка с backend

```sh
npm run build
# в ../endless-drawing-backend (PostgreSQL из его docker compose):
STATIC_DIR=../endless-drawing-frontend/dist cargo run
# здесь:
npm run test:integration   # два/три реальных браузерных контекста против :3000
```

Для JSON rollback-проверки запустить backend с `WS_MSGPACK_ENABLED=false` и тест с `E2E_WS_PROFILE=json npm run test:integration`. `E2E_RENDERER=canvas2d` проверяет fallback, `E2E_CAMERA='{"x":1000,"y":1000}'` задаёт воспроизводимую область; по умолчанию тест проверяет Binary frames и текущий renderer.

Тест рисует в случайной области мира, поэтому совместим с непустой dev-БД, но оставляет в ней удалённые (soft delete) тестовые штрихи — лучше использовать отдельную БД.

### iPhone / iPad в локальной сети

```sh
npm run dev:lan                     # Vite на 0.0.0.0:5173
# backend: разрешить Origin телефона (IP вашего Mac)
ALLOWED_ORIGINS=http://192.168.1.10:5173 cargo run
```

Открыть `http://192.168.1.10:5173` на устройстве. По HTTP страница не является secure context: UUID генерируются fallback-функцией через `crypto.getRandomValues`, остальное работает. Admin по HTTP не работает (нужны Secure cookies/WebAuthn).

Vite proxy `/ws`, `/api/admin/*`, `/healthz`, `/readyz` → `http://127.0.0.1:3000`. Для другого backend: `BACKEND_DEV_URL=http://127.0.0.1:8080 npm run dev`. Без запущенного backend холст открывается, но штрихи остаются неподтверждёнными (кратко сообщается об отсутствии соединения). В production-коде mock нет; E2E используют WS-двойник `tests/e2e/support/world.ts`. Сборка включает `dist/index.html`, `dist/about/index.html`, `dist/privacy/index.html`, `dist/admin/index.html` и общие assets: передавать backend целый `dist/`.

## Администратор и модерация

Предусмотрен отдельный служебный вход `/admin/`, без кнопок и ссылок на публичном холсте: логин + сложный пароль + обязательный WebAuthn passkey с user verification, включая Touch ID. Platform/synced passkeys разрешены; требуются основной и отдельный резервный credential, а не один синхронизированный ключ на двух устройствах. Нужны серверная сессия, CSRF-защита, выбор/подтверждение скрытия чужих штрихов с причиной, live-уведомление всех посетителей и закрытый аудит.

**Реализовано во фронтенде:** отдельный `/admin/` entry, EN/RU, server-session check, пароль → WebAuthn → verify, регистрация двух passkeys, read-only WS snapshot/live, панорамирование, выбор до 100 чужих штрихов, список UUID/причина/подтверждение, HTTP hide, проверка неопределённой операции/явный идентичный retry, 401/expiry/logout. Секреты/CSRF не сохраняются в Storage; публичный entry не загружает admin UI. Прямоугольное выделение пока не добавлено — множественный выбор кликами.

**Не считать production-интеграцию готовой:** API-контракт — `../endless-drawing-backend/docs/admin-api.md`, backend проверен локально; frontend HTTP/WS E2E использует mocks. Настоящие Touch ID, независимый резервный провайдер, cookie/CSRF/Origin на доверенном HTTPS, CLI provisioning и удаление в двух публичных контекстах нужно проверить совместно. HTTP Vite preview не обходит Secure cookies/серверную политику. Скрытый URL/Storage-флаг не авторизация. Инструкция и границы: [docs/admin-frontend.md](docs/admin-frontend.md).

## Управление

| Ввод | Действие |
| --- | --- |
| ЛКМ / перо / один палец | Активный инструмент: кисть / рука / ластик |
| Правый клик, Shift+F10, ContextMenu, долгое нажатие (500 мс) | Палитра |
| Зажатый Space (просто вести мышью или перетаскивать) / средняя кнопка | Временная рука: холст едет за курсором, при отпускании Space — прежний инструмент |
| Wheel / trackpad | Двухосевое панорамирование |
| Ctrl/⌘ + wheel, pinch трекпада | Зум вокруг курсора, 16–400% |
| Два пальца | Перемещение + pinch-зум; отменяет незавершённый штрих |
| Ctrl/⌘ + `=` / `-` / `0` (фокус на холсте) | Зум ×1.25 / ÷1.25 / 100% |
| Ctrl/⌘+Z, кнопка «Отменить» в палитре | Удалить последний свой штрих сессии |
| Escape | Закрыть палитру / отменить жест |

После первого касания пером (Apple Pencil) пальцы на этой странице только перемещают/масштабируют холст и не рисуют — ладонь не оставляет следов; касание пальцем во время штриха пером игнорируется. Оставшийся после pinch палец не начинает рисовать, нужен новый жест. На touch-ластик срабатывает по тапу/движению, а не при удержании.

Палитра доступна с клавиатуры; ввод в её полях не перехватывается горячими клавишами холста. Ширина 1–64 (world units, на экране масштабируется зумом), opacity 0.01–1, произвольный `#RRGGBB`, 6 быстрых цветов. По умолчанию round, #202020, 6, opacity 1. Допуск ластика — 4 CSS px на экране. На touch-устройствах цели ≥44 px, поле HEX 16 px (без автозума iOS); на телефонах палитра — нижний лист с учётом safe area.

У спрея диаметр крупинок — до 1 CSS px при 100%, масштабируется вместе с холстом. По решению владельца 18.11.2026 мелкие частицы применяются и к ранее сохранённым штрихам, без отдельного старого режима.

## Языки

Английский — по умолчанию, русский — для `ru` и региональных вариантов (`ru-RU`, `ru-KZ` и т. п.). При загрузке выбирается первый поддерживаемый язык из `navigator.languages` в порядке предпочтений браузера. При пустом списке используется `navigator.language`, без совпадений — английский. Например, `de-DE, ru-RU, en-US` → русский, `en-US, ru-RU` → английский.

Переведены палитра, подсказки, сообщения ошибок и accessibility-подписи; `html.lang` и формат процентов соответствуют языку. Название Endless Drawing и фраза проекта не переводятся. Язык не сохраняется в Storage, настройки кисти от него не зависят. После изменения языка браузера достаточно перезагрузить страницу. Никаких экранов выбора или постоянных переключателей.

## Поиск

Индексируется только публичный холст, без отдельной посадочной страницы. В `<head>` — описание (фраза и одно предложение на английском и русском), канонический URL, Open Graph и JSON-LD. `public/robots.txt` закрывает `/admin`, `/api` и служебные пробы; `public/sitemap.xml` перечисляет только `https://endlessdrawing.com/`. Краткое описание для моделей — `public/llms.txt`. `/admin/` остаётся `noindex` и в карту не входит.

Чтобы сайт начали обходить, владелец добавляет свойство в Google Search Console, Яндекс Вебмастер и Bing Webmaster и отправляет sitemap. Код подтверждения в репозиторий не зашит.

Публичный словарь и чистая функция определения языка — `src/i18n.ts`, отдельный admin-каталог — `src/admin/i18n.ts`; новые ключи проверяются TypeScript для обоих переводов. Дополнительные библиотеки и сетевые запросы переводов не нужны.

## Хранение и ограничения

Транспорт предлагает MessagePack v6 → v5 → v4 → v3 → v2 → явный JSON v1 на одном `/ws`; формат выбирается WebSocket subprotocol до hello. Общий кодек public/admin — `src/transport/`. В v6 входящий `path` — целые дельты в единицах 1/16, преобразуемые в обычные точки на границе кодека; ошибка ≤1/8 CSS px при zoom=4. Create по-прежнему отправляет float64 `points`. `WS_COMPACT_ENABLED=false` выбирает v5 для новых соединений; без `path` и без потери прежней точности. Контракт — backend [protocol-v6-compact.md](../endless-drawing-backend/docs/protocol-v6-compact.md). Сначала нужен dual-profile backend; старый backend без согласования subprotocol с новым клиентом несовместим. При повторной подписке v3 передаёт membership и догружает только отсутствующие strokes; первый вход/reconnect/resync остаются full snapshot. `WS_MANIFEST_ENABLED=false` на backend откатывает M2 к v2. M3 и информационные страницы опубликованы 18.11.2026: [результат выкладки](docs/transport-release.md). `WS_PRIORITY_ENABLED=false` отключает v4 для новых соединений, сохраняя v3.

- `localStorage`: `endless-drawing.preferences.v1` — инструмент и кисть.
- `sessionStorage`: `endless-drawing.camera.v1` — центр и zoom; `endless-drawing.session.v1` — 32-байтный base64url секрет сессии (отправляется только в WS `hello`); `endless-drawing.undo.v1` — UUID своих подтверждённых штрихов (до 500). Новая вкладка — новый секрет и стартовая точка из `hello.ack.spawn` (рядом со случайным живым штрихом, так посетители расходятся вслед за рисунком); в пустом мире — случайный центр в [-250, 250]. Закрытие вкладки завершает право удалять её штрихи.
- Геометрия хранится сервером; клиент держит кеш текущей подписки (до 20 000 штрихов / 1 000 000 точек, при переполнении — краткое сообщение) и до 64 неподтверждённых штрихов. Подписка — 3× видимая область, не шире 30 000 world units по оси, со сдвигом вперёд по направлению движения; переподписка, когда впереди остаётся меньше половины запаса, или при сильном увеличении. Штрихи нового snapshot появляются по мере прихода chunks. Профиль MessagePack v4 передаёт видимую часть раньше запаса (состав снимка прежний); v3/v2/JSON остаются fallback. Новый порядок загрузки не меняет композицию по seq.
- Повреждённые/недоступные Storage не ломают приложение (секрет тогда живёт до перезагрузки).
- Клиентские лимиты ниже серверных: create 5/1.1 с, delete 20/1.1 с, subscribe ≤4/с; ack timeout 12 с → переподключение и повтор того же UUID.
- Opacity одного штриха применяется один раз. Подтверждённые штрихи лежат в кеше тайлов: WebGL2 хранит их в текстурах, Canvas 2D — в `src/tiles.ts`. Сдвиг и новый штрих копируют готовые тайлы; заново рисуются только тайлы, которых штрих коснулся. Кадр — dirty RAF, не постоянный цикл.
