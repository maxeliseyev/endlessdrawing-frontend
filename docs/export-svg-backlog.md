# Бэклог: сохранить выделенную область в SVG

Статус: **в бэклоге по решению владельца 17.11.2026, не реализовано.** До реализации действует прежний запрет на экспорт из `AGENTS.md`; эта запись разрешает только описанную здесь фичу — векторный SVG выбранной области на устройство пользователя. По сути это тот же скриншот, только в векторе. Другие форматы (PNG, PDF, «весь мир», публичные ссылки на экспорт) не нужны (решение владельца 17.11.2026).

## Пользовательский сценарий

1. Палитра (правый клик / Shift+F10 / long press) → пункт «Сохранить область в SVG». Отдельной кнопки на холсте нет.
2. Режим выделения: протянуть прямоугольник мышью, пером или одним пальцем. Два пальца, колесо и Space по-прежнему двигают и масштабируют. Escape / тап вне области / повторный выбор пункта — отмена.
3. Пока идёт выделение — только рамка и маленькая временная подсказка с «Сохранить» / «Отмена» (по правилам продукта: не постоянная панель, исчезает после действия).
4. «Сохранить» → файл `endless-drawing.svg` на устройство (без координат в имени): `<a download>` + Blob `image/svg+xml`; на iOS Safari при необходимости `navigator.share({ files })`.

## Данные и ограничения

- Источник — подтверждённые штрихи из текущей сцены (`SharedScene`), без pending и скрытых. Область ограничена видимой частью экрана в момент выделения: она всегда внутри текущей подписки, поэтому данные полные. Для больших областей пользователь отдаляется (до 16%), отдельный запрос к серверу не нужен.
- Сохранять только после `phase === 'ready'` (snapshot завершён), иначе предупреждать, что область ещё догружается.
- Лимиты: до 20 000 штрихов / 1 000 000 точек сцены; если SVG получается больше ~20 МБ — краткое сообщение вместо зависания.
- Порядок элементов — по `seq`, как на экране.

## Геометрия SVG (тот же контракт, что у renderer)

- `viewBox` = выделение в world units, координаты сдвинуты к его левому верхнему углу и округлены до 0.01 (без потери точности на `WORLD_LIMIT`). Белый фон — `<rect>`. Штрихи, пересекающие границу, обрезает `viewBox`.
- round/square — один `<path>` на штрих: `stroke-width` = ширина, `stroke-linecap`/`stroke-linejoin` round или square/bevel, `stroke-opacity` (обводка одного элемента композитится один раз — самопересечения не темнеют, как в Canvas). Точка — `<circle>` / `<rect>`.
- chisel — полигоны `chiselPolygons` одним `<path>` с `fill-rule="nonzero"`; spray — частицы `sprayParticles` одним `<path>` из дуг. Алгоритмы общие с `src/brush-geometry.ts`, менять их нельзя (версионирование — `docs/brushes.md`).
- Никаких метаданных: ни UUID, `own`, секретов и данных о владельцах, ни `<title>`/`<desc>`, подписи, домена или координат области. Только геометрия и фон.

## Решено владельцем (17.11.2026)

- Подпись/атрибуция в файле не нужна, метаданные не сохраняются.
- PNG не нужен: только SVG.

## Тесты при реализации

- Unit: сериализатор SVG (golden-файлы для всех кистей, opacity, обрезка, сдвиг координат, отсутствие любых метаданных и приватных полей).
- E2E: выделение мышью/touch, отмена, скачивание (`page.waitForEvent('download')`), три движка; ручная проверка на iPhone/iPad (сохранение в «Файлы»).
