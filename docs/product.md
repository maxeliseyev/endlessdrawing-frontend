# Endless Drawing

- **Название:** Endless Drawing
- **Домен:** https://endlessdrawing.com
- **Описание:** One drawing. Everyone. Forever.

## Принципы

Один общий бесконечный белый холст для всех. Человек открывает сайт и сразу находится на холсте.

**Никакого приветственного экрана. Никаких баннеров. Только общий холст.**

Нет регистрации, landing page, onboarding, шапки, навигации, постоянной панели инструментов, рекламных/промо-блоков или приветственной надписи. Бренд и описание — в метаданных страницы и документации, не поверх рисунка. Не подставлять демонстрационные рисунки вместо пустой области общего мира.

Палитра открывается по запросу у курсора правым кликом; клавиатурная альтернатива — Shift+F10 / ContextMenu. Кратковременная ненавязчивая ошибка при реальном сбое допустима по ТЗ; постоянный сетевой баннер не нужен.

Фраза «Forever» описывает идею проекта, но не заменяет технические гарантии хранения. Неподтверждённые сервером штрихи нельзя объявлять сохранёнными.

## Кисти, зум и touch

В палитре четыре формы: круглая, квадратная, **Косое перо / Chisel pen** (плоский наконечник `/` под -45°) и **Спрей / Spray** (детерминированные частицы, воспроизводимые по UUID/траектории). Цвет, толщина и opacity общие; никаких постоянных панелей. Геометрия и необходимые изменения backend: [brushes.md](brushes.md). Пока новые формы работают локально, не считаются поддержанными старым round/square WS-контрактом.

Touch и Apple Pencil (iPhone/iPad) и ограниченный зум 25–400% реализованы по решению владельца 16.11.2026: [tablet-input-backlog.md](tablet-input-backlog.md). Второй палец и long press отменяют незавершённый штрих без отправки; постоянных touch-панелей нет.

## Закрытая модерация

Администратор должен иметь возможность скрывать незаконные рисунки, в том числе чужие и состоящие из нескольких штрихов. Отдельный служебный `/admin/` — единственное исключение из запрета дополнительных страниц. На публичном холсте нет ссылок, кнопок входа, скрытых пунктов и административных горячих клавиш.

Вход: логин + сгенерированный сложный пароль + обязательный WebAuthn passkey с user verification, в первую очередь Touch ID. Platform/synced passkeys разрешены, аппаратный ключ и CA trust store не обязательны. Основной и резервный credentials регистрируются отдельно; один iCloud credential на нескольких устройствах не считается двумя независимыми резервами. Это нативный браузерный аналог подхода с ключевой парой, не загрузка приватного SSH-ключа. Авторизация — только серверная; скрытость адреса не даёт защиты. Публичные посетители по-прежнему могут удалять только собственные штрихи.

Выделение, подтверждение, причина, soft delete, немедленное исчезновение у подписчиков и закрытый аудит — обязательны перед публичным запуском. Frontend входа/enrollment, выбора и hide уже реализован; soft delete/audit/broadcast обеспечивает backend. Совместная настоящая HTTPS/Touch ID приёмка ещё не выполнена. Требования: [moderation.md](moderation.md), текущая реализация и gates: [admin-frontend.md](admin-frontend.md).

## Языки

Английский по умолчанию; русский для `ru` и всех `ru-*`. При загрузке следуем порядку `navigator.languages`, выбирая первый поддерживаемый язык; если список пуст — используем `navigator.language`, если совпадений нет — `en`. Неподдерживаемый первый язык не мешает выбрать поддерживаемый следующий. `en-US, ru-RU` → английский, `de-DE, ru-RU` → русский.

Локализуются подписи инструментов и контролов, клавиатурные подсказки, ошибки и accessibility-текст. Название, домен и **One drawing. Everyone. Forever.** одинаковы для всех. Без экрана выбора языка и постоянного переключателя: язык определяется при каждой загрузке, не хранится отдельно и не влияет на геометрию/настройки кисти.
